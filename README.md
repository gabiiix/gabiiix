### ⚡ VSD Calculator

Engineering application developed with **Flutter and Dart** for electrical calculations related to Variable Speed Drives (VSDs) and electric motors.

Main features:

- Voltage drop calculations
- Transformation ratio
- Current limits
- Underload and overload calculations
- kVA calculations
- Motor torque calculations
- NEMA voltage unbalance
- Phase-to-phase resistance unbalance

**Tech stack:** Flutter · Dart

🔗 [View VSD Calculator repository](https://github.com/gabiiix/vsd-calculator)
